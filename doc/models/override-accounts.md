
# Override Accounts

Data to use to set values of test accounts. Some values cannot be specified in the schema and will instead will be calculated from other test data in order to achieve more consistent, realistic test data.

*This model accepts additional fields of type object.*

## Structure

`OverrideAccounts`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `Type` | [`OverrideAccountType`](../../doc/models/override-account-type.md) | Required | `investment:` Investment account<br><br>`credit:` Credit card<br><br>`depository:` Depository account<br><br>`loan:` Loan account<br><br>`payroll:` Payroll acccount<br><br>`other:` Non-specified account type<br><br>See the [Account type schema](https://plaid.com/docs/api/accounts#account-type-schema) for a full listing of account types and corresponding subtypes. |
| `Subtype` | [`AccountSubtype`](../../doc/models/account-subtype.md) | Required | See the [Account type schema](https://plaid.com/docs/api/accounts/#account-type-schema) for a full listing of account types and corresponding subtypes. |
| `StartingBalance` | `double` | Required | If provided, the account will start with this amount as the current balance. |
| `ForceAvailableBalance` | `double` | Required | If provided, the account will always have this amount as its  available balance, regardless of current balance or changes in transactions over time. |
| `Currency` | `string` | Required | ISO-4217 currency code. If provided, the account will be denominated in the given currency. Transactions will also be in this currency by default. |
| `Meta` | [`Meta`](../../doc/models/meta.md) | Required | Allows specifying the metadata of the test account |
| `Numbers` | [`Numbers`](../../doc/models/numbers.md) | Required | Account and bank identifier number data used to configure the test account. All values are optional. |
| `Transactions` | [`List<TransactionOverride>`](../../doc/models/transaction-override.md) | Required | Specify the list of transactions on the account. |
| `Holdings` | [`HoldingsOverride`](../../doc/models/holdings-override.md) | Optional | Specify the holdings on the account. |
| `InvestmentTransactions` | [`InvestmentsTransactionsOverride`](../../doc/models/investments-transactions-override.md) | Optional | Specify the list of investments transactions on the account. |
| `Identity` | [`OwnerOverride`](../../doc/models/owner-override.md) | Required | Data about the owner or owners of an account. Any fields not specified will be filled in with default Sandbox information. |
| `Liability` | [`LiabilityOverride`](../../doc/models/liability-override.md) | Required | Used to configure Sandbox test data for the Liabilities product |
| `InflowModel` | [`InflowModel`](../../doc/models/inflow-model.md) | Required | The `inflow_model` allows you to model a test account that receives regular income or make regular payments on a loan. Any transactions generated by the `inflow_model` will appear in addition to randomly generated test data or transactions specified by `override_accounts`. |
| `Income` | [`IncomeOverride`](../../doc/models/income-override.md) | Optional | Specify payroll data on the account. |
| `AdditionalProperties` | `object this[string key]` | Optional | - |
