# Link Token Get

The `/link/token/get` endpoint gets information about a previously-created `link_token` using the
`/link/token/create` endpoint. It can be useful for debugging purposes.

Find out more here: [/api/tokens/#linktokenget](/api/tokens/#linktokenget)

```csharp
LinkTokenGetAsync(
    Models.LinkTokenGetRequest body)
```

## Authentication

This endpoint requires [PLAID-CLIENT-ID](../../doc/auth/custom-header-signature.md) **AND** [PLAID-SECRET](../../doc/auth/custom-header-signature-1.md) **AND** [Plaid-Version](../../doc/auth/custom-header-signature-2.md)

## Parameters

| Parameter | Type | Tags | Description |
|  --- | --- | --- | --- |
| `body` | [`LinkTokenGetRequest`](../../doc/models/link-token-get-request.md) | Body, Required | - |

## Response Type

**200**: OK

This method returns an [`ApiResponse`](../../doc/api-response.md) instance. The `Data` property of this instance returns the response data which is of type [Models.LinkTokenGetResponse](../../doc/models/link-token-get-response.md).

## Example Usage

```csharp
LinkTokenGetRequest body = new LinkTokenGetRequest
{
    LinkToken = "link_token4",
};

try
{
    ApiResponse<LinkTokenGetResponse> result = await linkApi.LinkTokenGetAsync(body);
}
catch (ApiException e)
{
    Console.WriteLine(e.Message);
}
```

# Link Token Create

The `/link/token/create` endpoint creates a `link_token`, which is required as a parameter when initializing Link. Once Link has been initialized, it returns a `public_token`, which can then be exchanged for an `access_token` via `/item/public_token/exchange` as part of the main Link flow.

A `link_token` generated by `/link/token/create` is also used to initialize other Link flows, such as the update mode flow for tokens with expired credentials, or the Payment Initiation (Europe) flow.

Find out more here: [/api/tokens/#linktokencreate](/api/tokens/#linktokencreate)

```csharp
LinkTokenCreateAsync(
    Models.LinkTokenCreateRequest body)
```

## Authentication

This endpoint requires [PLAID-CLIENT-ID](../../doc/auth/custom-header-signature.md) **AND** [PLAID-SECRET](../../doc/auth/custom-header-signature-1.md) **AND** [Plaid-Version](../../doc/auth/custom-header-signature-2.md)

## Parameters

| Parameter | Type | Tags | Description |
|  --- | --- | --- | --- |
| `body` | [`LinkTokenCreateRequest`](../../doc/models/link-token-create-request.md) | Body, Required | - |

## Response Type

**200**: OK

This method returns an [`ApiResponse`](../../doc/api-response.md) instance. The `Data` property of this instance returns the response data which is of type [Models.LinkTokenCreateResponse](../../doc/models/link-token-create-response.md).

## Example Usage

```csharp

{
    ClientName = "client_name0",
    Language = "language8",
    CountryCodes = new List<CountryCode>
    {
        CountryCode.Ca,
    },
    User = new LinkTokenCreateRequestUser
    {
        ClientUserId = "client_user_id4",
    },
};

try
{
    ApiResponse<LinkTokenCreateResponse> result = await linkApi.LinkTokenCreateAsync(body);
}
catch (ApiException e)
{
    Console.WriteLine(e.Message);
}
```
